Computer Graphics Course & Interactive Lab Hub
An interactive web-based platform and laboratory environment built for university-level Computer Graphics coursework. This platform combines structured theoretical study materials, interactive visualizers for classic graphics algorithms, a live browser-based C++ execution playground, and a full mock examination system.

Key Features

1. Interactive C++ Code Sandbox & Execution Runner

Pre-Built Visualizers:- Interactive HTML5 Canvas representations of legacy Turbo C++ graphics scripts (graphics.h), including DDA, Bresenham line drawing, circle/ellipse algorithms, 2D/3D transformations, and animations (bouncing balls, moving vehicles, flag renderings).

Live In-Browser C++ Editor:- Embedded code editor with syntax highlighting, auto-indentation, and starter templates.

Code Execution:- Run C++ code directly in the browser to view standard console output (std::cout) in an integrated terminal, with graphical primitives rendered on a real-time canvas.
