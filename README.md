# Computer Graphics Course & Interactive Lab Hub

An interactive web-based platform and laboratory environment built for university-level Computer Graphics coursework. This platform combines structured theoretical study materials, interactive visualizers for classic graphics algorithms, a live browser-based C++ execution playground, and a full mock examination system.

# Key Features

1. Interactive C++ Code Sandbox & Execution Runner

- Pre-Built Visualizers:- Interactive HTML5 Canvas representations of legacy Turbo C++ graphics scripts (graphics.h), including DDA, Bresenham line drawing, circle/ellipse algorithms, 2D/3D transformations, and animations (bouncing balls, moving vehicles, flag renderings).

- Live In-Browser C++ Editor:- Embedded code editor with syntax highlighting, auto-indentation, and starter templates.

- Code Execution:- Run C++ code directly in the browser to view standard console output (std::cout) in an integrated terminal, with graphical primitives rendered on a real-time canvas.

2. Comprehensive Course Curriculum & Theory

Chapter 1: Overview & Video Display Devices

- Display hardware mechanisms: Refresh CRT, Raster-Scan vs. Random-Scan (Vector), LCD, LED, and Plasma.Color techniques: Beam-Penetration vs. Shadow-Mask methods.

Chapter 2: Line, Circle & Primitive Drawing Algorithms

- Digital Differential Analyzer (DDA) and Bresenham’s Line Algorithms.Midpoint Circle and Ellipse derivations with 8-way and 4-way symmetry analysis.

Chapter 3: 2D Transformations & Clipping

- Translation, Scaling, Rotation, and Matrix Homogeneous Coordinates.Cohen-Sutherland (Outcodes) and Liang-Barsky line clipping algorithms.

Chapter 4: 3D Graphics & Projections

- 3D transformations and parallel vs. perspective projection models.

3. Timed Mock Examination Engine

- 100 Question Test Bank: Multiple-choice, true/false, and code/pixel trace prediction questions.

- Exam Controls: Configurable countdown timers, question flagging, and dynamic progress grids.

- Analytics: Detailed score breakdowns, performance metrics by topic, and complete answer explanations.
